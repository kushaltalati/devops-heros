$ kubectl -n studytrack logs studytrack-broken-image-68fd7b8cf6-8spbh
Error from server (BadRequest): container "backend" in pod "studytrack-broken-image-68fd7b8cf6-8spbh" is waiting to start: trying and failing to pull image

ROOT CAUSE: the tag 'does-not-exist' is not in ghcr.io/kushaltalati/studytrack-backend (the registry answers 'manifest unknown' / not found), so kubelet cannot pull and backs off.
FIX: point the Deployment at a tag that exists (latest, or the sha tag the pipeline pushed).

$ kubectl -n studytrack set image deployment/studytrack-broken-image backend=ghcr.io/kushaltalati/studytrack-backend:latest
